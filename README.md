# Motorcycle Menu Selector

برنامه دسکتاپ برای انتخاب منوی تشخیص موتورسیکلت و سواری — شبیه صفحه‌نمایش دستگاه دیاگ، بدون نیاز به باز بودن اکسل.

Desktop app for diagnostic menu selection (motorcycle & passenger cars), styled like a real scanner screen.

---

## ویژگی‌ها / Features

- صفحه انتخاب به سبک دستگاه دیاگ (برند → مدل → واحد → زیرواحد → آیتم‌ها)
- پشتیبانی از **موتورسیکلت** و **سواری** (شرکت‌های خودروساز)
- اتصال به پوشه اکسل‌های `Diag_Menu` و `Diag_Database`
- میان‌بر باز کردن فایل اکسل فعال و دیتابیس
- ذخیره مسیرها در تنظیمات (پاپ‌آپ مدرن)
- **به‌روزرسانی خودکار فایل‌های اکسل از گیت‌هاب** (نوتیف + تأیید + دانلود)
- خروجی قابل‌اجرا با `build_exe.bat` (PyInstaller)

---

## نیازمندی‌ها / Requirements

- Python **3.9+**
- ویندوز (توصیه‌شده برای exe و مسیرهای پیش‌فرض)
- پکیج‌ها:

```bash
pip install -r requirements.txt
```

| پکیج       | کاربرد                          |
|------------|----------------------------------|
| `openpyxl` | خواندن فایل‌های اکسل دیاگ       |
| `Pillow`   | آیکون‌ها و تصاویر برند          |

## اجرا / Run

```bash
python motorcycle_menu_app.py
```

اگر هنوز پوشه اکسل تنظیم نشده باشد، از `tree_data.json` نمونه استفاده می‌شود.

### تنظیم مسیر اکسل

1. برنامه را باز کنید → کارت **تنظیمات**
2. پوشه **Diag_Menu** (منوی دیاگ) و **Database** را انتخاب کنید
3. برای موتورسیکلت فایل `18_MotorCycle.xlsm` داخل همان پوشه انتظار می‌رود

---

## ساخت فایل exe / Build EXE

روی ویندوز روی `build_exe.bat` دوبار کلیک کنید. خروجی معمولاً در:

```text
dist\MotorcycleMenuSelector.exe
```

## به‌روزرسانی خودکار اکسل از گیت‌هاب

وقتی نسخهٔ جدیدی از فایل‌های اکسل را روی گیت‌هاب آپلود می‌کنید، همکاران با باز کردن برنامه یک نوتیف می‌بینند و بعد از تأیید، فایل‌ها خودکار دانلود می‌شوند.

### ۱) ساختار ریپوی اکسل روی گیت‌هاب

یک ریپو (عمومی یا خصوصی) بسازید و فایل‌ها را به این شکل بگذارید:

```text
REPO/
├── excel_versions.json          ← مانیفست نسخه‌ها (الزامی)
├── Diag_Menu/
│   ├── 18_MotorCycle.xlsm
│   ├── 01_IranKhodro.xlsm
│   ├── 02_Saipa.xlsm
│   └── ...
└── Diag_Database/
    └── (فایل‌های دیتابیس در صورت نیاز)
```

نمونهٔ `excel_versions.json` در فایل `excel_versions.example.json` همین پروژه است.

### ۲) ساخت / به‌روز کردن مانیفست

هر بار که اکسل را عوض می‌کنید:

1. فایل(های) جدید را در پوشهٔ مربوطه روی گیت‌هاب commit و push کنید.
2. هش SHA-256 فایل را حساب کنید (پاورشل):

```powershell
Get-FileHash -Algorithm SHA256 ".\Diag_Menu\18_MotorCycle.xlsm"
```

یا در لینوکس/مک:

```bash
sha256sum Diag_Menu/18_MotorCycle.xlsm
```

3. مقدار `version` و `sha256` را در `excel_versions.json` به‌روز کنید و push کنید.

مثال:

```json
{
  "version": "1.2.0",
  "updated_at": "2026-08-23T15:00:00",
  "files": {
    "Diag_Menu/18_MotorCycle.xlsm": {
      "version": "1.2.0",
      "sha256": "abc123..."
    }
  }
}
```

### ۳) تنظیم برنامه برای همکاران

1. برنامه را باز کنید → **تنظیمات**
2. در بخش «به‌روزرسانی اکسل از گیت‌هاب» این آدرس را وارد کنید:

```text
https://raw.githubusercontent.com/USERNAME/REPO_NAME/main
```

(به‌جای `USERNAME` و `REPO_NAME` و در صورت نیاز `main` را با branch واقعی عوض کنید.)

3. اگر ریپو **خصوصی** است، یک Personal Access Token با دسترسی `repo` بسازید و در فیلد توکن بگذارید.
4. **ذخیره آدرس** را بزنید.
5. با **بررسی به‌روزرسانی** می‌توانید دستی چک کنید.

از این به بعد، هر بار که برنامه باز شود (حدود ۱٫۵ ثانیه بعد)، اگر نسخهٔ جدیدی باشد نوتیف می‌آید؛ بعد از تأیید کاربر، فایل‌ها دانلود و جایگزین می‌شوند و داده دوباره بارگذاری می‌شود.

> **نکته:** پوشه‌های محلی `Diag_Menu` و `Diag_Database` باید از قبل در تنظیمات برنامه مشخص شده باشند تا فایل‌های دانلودشده در همان مسیر ذخیره شوند.
